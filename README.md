# canalizationENV

This repository contains scripts organized into four main groups:

### A. Data Preprocessing
`raw-1`, `raw-2`, and `raw-3` are scripts for preprocessing the spatiotemporal data of *C. elegans* embryogenesis.

### B. Basic Variable Generation
`1`–`12` are scripts used to generate the basic variables for this study based on the preprocessed data.

### C. Visualization of Basic Findings
`Plot-1` to `Plot-26` are scripts for visualizing the basic findings related to the mathematical negative-feedback mechanism.

### D. Physical Kinematic Mechanism
`Mechanism-1` to `Mechanism-12` are scripts for revealing the physical kinematic mechanism of the golden-ratio-embedded self-similarity equation.
